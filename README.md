# Thesis-RL

Offline reinforcement learning for prescriptive process monitoring on the SimBank simulator.

## What this is about

Abstract. Offline reinforcement learning (RL) is increasingly adopted
for prescriptive process monitoring (PresPM), yet there is no systematic
overview of how researchers construct the environments in which
these agents learn. This study addresses that gap by proposing
a six-category framework that classifies environment construction
approaches along a spectrum from direct data-based methods to fully
domain knowledge-based simulators. Each category is characterised in
terms of data abstraction, distributional shift exposure, interpretability
and counterfactual capacity. To empirically ground the framework, nine
methods spanning four categories are benchmarked on SimBank, a
simulator that models a bank loan application process with realistic
intervention structures such as procedure selection, customer contact
timing and interest rate setting. Experiments are conducted under
both unconfounded and confounded training data, across sequential
intervention settings of increasing complexity.

Two data conditions are studied. **RCT** reflects an idealized world where past actions were taken uniformly at random. **CONF** is more realistic: data was generated by a biased policy, so off-policy estimation must deal with confounding.

Nine methods are compared under a standardized evaluation protocol, spanning tabular Q-iteration (**K-Means-FQI**), sequence-based deep Q-networks (**LSTM-DQN**, **RIMS-DQN**), conservative Q-learning variants (**CQL-SN**, **CQL-MN**), and causal-reward DQN approaches combining an outcome model with a downstream DQN (**LSTM-DQN-GBR**, **LSTM-DQN-SLearner**, **LSTM-DQN-DragonNet**, **LSTM-DQN-TabPFN**).

Two additional experiments sit on top of the main comparison. `run_all_steps.py` varies how many of the three intervention points are RL-controlled in cumulative order (1, 2, or all 3), isolating the marginal contribution of each successive intervention. `run_intervention_combos.py` trains LSTM-DQN independently on every non-empty subset of {int0, int1, int2} (seven subsets), testing whether joint optimization over all interventions outperforms subset-specific training.

│   ├── CQL-SN/                   Single-network conservative Q-learning

│   ├── LSTM-DQN-GBR/             Causal hybrid: GBR S-learner + LSTM-DQN
│   ├── LSTM-DQN-SLearner/        Causal hybrid: LSTM S-learner + LSTM-DQN
│   ├── LSTM-DQN-TabPFN/          Causal hybrid: TabPFN S-learner + LSTM-DQN
│   └── LSTM-DQN-DragonNet/       Causal hybrid: DragonNet + LSTM-DQN

Every method directory has the same four scripts:

| File | Role |
|---|---|
| `generate_data.py` | Delegate to `methods/shared/generate_data.py` |
| `convert_data.py` | Extract `(prefix, action, reward, next_prefix, terminal, intervention)` transitions |
| `train.py` | Train the policy / Q-function |
| `evaluate.py` | Evaluate via `shared.evaluate_policy` against Bank and Random baselines |

## Running experiments

### Cumulative steps (marginal contribution per intervention)

```bash
python run_all_steps.py                          # all 9 methods, steps {1,2,3}, RCT + CONF
python run_all_steps.py --methods LSTM-DQN       # single method
python run_all_steps.py --steps 3 --no_confounded
```

Output: `results/all_results.json`

### Full 3-step retrain (canonical baseline)

```bash
python -u retrain_all_3step.py                   # all 9 methods × 5 seeds × RCT + CONF
python -u retrain_all_3step.py --suffixes CONF --methods LSTM-DQN
```

Output: updates `results/all_results.json`

### Intervention subset experiment (LSTM-DQN)

```bash
python -u run_intervention_combos.py             # CONF, all 7 subsets, all 5 seeds
python -u run_intervention_combos.py --suffix RCT
python -u run_intervention_combos.py --subsets 012 --seeds 42
```

Trains LSTM-DQN independently on each subset with per-seed train/val splits. Output: `results/lstm_joint_vs_subset.json` (CONF) and `results/lstm_joint_vs_subset_rct.json` (RCT).

### Figures

```bash
python plot_results.py                           # writes results/figures/fig*.{pdf,png}
```

## Evaluation protocol

Shared across every method and script:

- **5 seeds**: `[42, 123, 456, 789, 1024]`
- **Training set**: `n_cases = 10000`
- **Evaluation**: 1000 SimBank episodes per seed
- **Conditions**: RCT and CONF (`--confounded`, `delta=0.95`)
- **Intervention points** (`N_ACTIONS = [2, 2, 3]`):
  - Int 0 `choose_procedure`: standard / priority
  - Int 1 `contact_HQ`: contact / skip
  - Int 2 `set_ir_3_levels`: 7% / 8% / 9%
- **Baselines**: Bank policy (rule-based heuristic) and Random policy
